# Map layers — the materialized products in `web/public/maps/`

A catalog of the model-output GeoJSONs served with the site, so it's clear what
already exists (and what still needs materializing into the queryable database).
These are **display** layers — the `/map` agent can *show* them, but its `area`
metric can only *query* what's in PostGIS (RF riparian extent). See
[the extent-coverage note](STATUS.md) and the
[map-agent runtime ADR](decisions/2026-08-18-map-agent-runtime.md).

## What's there

Generated by `experiments/riparian_extent/` tools (`deploy_extent_map.py`,
`deep_time_invasives.py`) into `.tmp/`, then copied into `web/public/maps/`.
Properties are minimal: `class` (`riparian` | `invasive`) and `min_prob`.

| file | product | model | reach |
|---|---|---|---|
| `present-extent-2020.geojson` | riparian extent | RF | Farmington corridor |
| `present-invasive-in-corridor.geojson` | **invasive** | — | corridor |
| `deep-invasive-1990/2000/2010/2020.geojson` | **invasive spread over time** (Stage 3) | — | corridor |
| `extent-bloomfield-rf.geojson` | riparian extent | RF | Bloomfield |
| `fm_bloomfield.geojson` | riparian extent | **OlmoEarth (FM)** | Bloomfield |
| `fm_malpais.geojson` | riparian extent | **OlmoEarth (FM)** | Malpais |
| `reach-malpais-rf.geojson` | riparian extent | RF (LORO, co-located) | Malpais |
| `nmripmap-bloomfield.geojson`, `truth_malpais.geojson` | NMRipMap ground truth | — | Bloomfield / Malpais |

## Where they're used

- **Homepage story map** (`web/src/scripts/story-client.ts`): `present-extent-2020`
  and `present-invasive-in-corridor` only.
- **`/map` ("ask the map")** (`web/src/scripts/map-agent-client.ts`, the `PRODUCTS`
  const): a "Model layers" legend toggles **RF riparian** (green), **OlmoEarth FM
  riparian** (teal), and **invasive** (red).

## Still to do (the queryable half)

Displaying a layer is not the same as the agent being able to answer about it. For
the agent to report **invasive share** or **FM extent** (not just RF), those
products must land in the queryable store:

- `silver.riparian_extent` needs `method = 'olmoearth'` rows (today it is RF-only).
- an **invasive** table (per-reach or per-cell) does not exist yet.
- both must reach the **box PostGIS** (the 18 MB subset the deployed agent queries).

Until then, `/api/agent/area` answers RF riparian extent only, and the map shows
the FM/invasive products as static overlays.
